Dán đường dẫn kho mã nguồn công khai để kiểm tra nhanh trên trình duyệt, hoặc dùng GitHub Actions chạy REA thực sự trên Ubuntu. Kết quả đi kèm bằng chứng, có thể chuyển sang ChatGPT để nghiên cứu chuyên sâu.

Phạm vi thực tế

Trình duyệt không tự dịch ngược máy mã native thành pseudocode. Tệp .exe/.dll cần engine chuyên dụng trên máy chủ được cấu hình phù hợp. Workflow mẫu hiện chỉ chạy chế độ JS/Electron tĩnh của REA.

Chỉ sử dụng mã và phần mềm bạn có quyền phân tích. Không gửi bí mật, mã nguồn riêng tư hoặc mẫu độc hại lên repository công khai.

Phân tích mã nguồn GitHub

Truy xuất danh sách tệp và kiểm tra tĩnh một mẫu giới hạn các tệp JavaScript/TypeScript. Không tải hoặc chạy chương trình.

REA trên GitHub Actions

GitHub Actions cấp máy Ubuntu tạm thời, cài Node.js và chạy gói rea-agents@6.7.0. Bạn không phải cài đặt thứ gì lên Windows.

Workflow REA Cloud · JavaScript/Electron nhận repository GitHub công khai và chạy analyze-javascript-application ở chế độ không thực thi mục tiêu. Đây là kết quả REA khác với bước quét nhanh trong trình duyệt.
  1. Nhấn Mở GitHub Actions bên dưới, đăng nhập tài khoản được phép chạy workflow.
  2. Chọn Run workflow, nhập repository theo dạng owner/repo (không cần URL dài).
  3. Sau khi run kết thúc, mở run đó → Artifacts → tải rea-evidence.
  4. Mở tab ChatGPT, dùng prompt mẫu và đính kèm tệp JSON vừa tải.

Máy GitHub Actions phải có quyền chạy workflow. Artifact và nhật ký của repo public có thể truy cập công khai; không dùng workflow này cho dữ liệu bí mật. Không hỗ trợ Windows native/Ghidra ở bản mẫu.

Đưa bằng chứng sang ChatGPT

Sao chép lời nhắc có thông tin từ lần quét gần nhất, sau đó mở ChatGPT và dán vào cuộc trò chuyện. Nếu đã chạy Cloud REA, đính kèm JSON evidence để nâng độ tin cậy.

Hãy phân tích phần mềm theo phương pháp REA: xác định module, dependency, luồng dữ liệu, IPC Electron, ranh giới tin cậy, và điểm rủi ro. Với mỗi kết luận phải dẫn nguồn tệp:dòng; phân biệt quan sát, suy luận và chưa xác minh.

Những gì ChatGPT có thể làm

Giải thích kiến trúc, hình thành giả thuyết và đề xuất kiểm tra tiếp theo dựa trên evidence. ChatGPT không có quyền truy cập trực tiếp đến REA trên runner chỉ vì trang web này đang mở; cần gửi evidence hoặc kết nối một backend/MCP từ xa riêng.
